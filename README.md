# Confaero — Conference Companion App

A Flutter app that helps conference attendees, organizers, and sponsors manage events, connect with people, and stay organized.

---

## What It Does

| For Attendees | For Organizers | For Sponsors |
|---|---|---|
| Browse events & schedules | Manage sessions & attendees | Track leads & analytics |
| Connect with other attendees | Send announcements | Capture attendee info |
| Chat & network in real-time | Coordinate volunteers | View engagement stats |
| Save notes & resources | Handle check-ins | |
| Scan QR codes & check in | | |

---

## Tech at a Glance

- **Flutter** — Cross-platform (Android, iOS, Web, Windows)
- **GetX** — State management & navigation
- **GoRouter** — Screen routing
- **Dio** — API calls
- **Socket.IO** — Real-time chat & notifications
- **Table Calendar** — Schedule views

## Inside `lib/`

### `core/` — Shared Tools

The foundation everything else builds on:

- **Config** — App routes & light/dark themes
- **Constants** — Colors, text, API endpoints
- **Services** — API calls, caching, real-time socket, connectivity checks
- **Helpers** — Logging, toasts, local storage
- **DI** — Dependency injection (GetX)
- **Exceptions** — Custom error types

### `features/` — App Screens (29 Modules)

Grouped by what they handle:

**Getting In**
- `auth` — Login, signup, password reset, OTP
- `onboarding` — First-time app intro

**Main Experience**
- `attendees` — Home screen, profile, documents, photos, sponsors, jobs, settings (largest module — 131 files)
- `Events` — Event listings & details
- `agenda` — Calendar & session schedule
- `speakers` — Speaker dashboard

**Connecting**
- `message` — Real-time chat
- `connection` — Send & accept connection requests
- `community` — Community announcements
- `announcements` — Create & manage announcements
- `notification` — Push & in-app alerts

**Content**
- `documents` — Event documents
- `photos` — Photo galleries
- `resources` — Downloadable resources
- `notes` — Personal notes
- `profile` — User profile data & service

**Role Dashboards**
- `organizer` — Organizer tools & session forms
- `organizer_messaging` — Organizer chat & conversations
- `sponsor_dashboard` — Sponsor lead capture & stats
- `sponsors` — Sponsor listings & service
- `reviewer` — Review submissions
- `volunteer` — Task management
- `booth_management` — Booth controls

**Other**
- `bottomNavbar` — Navigation bar (changes per role)
- `mainattendees` — Attendee listing & browse
- `invitations` — Event invitations
- `poster_assign` — Poster assignments
- `job` — Job postings
- `video_conference` — Live video sessions

### `presentations/` — Reusable Widgets

Shared UI building blocks used across screens:

- Custom buttons, text fields, loaders
- Network image wrapper with caching
- Theme switcher (light/dark)

### `global/` — Generated Files

Auto-generated by `flutter_gen` — makes asset references type-safe so you don't typo a path.

## User Roles

The app looks different depending on who's logged in:

| Role | What They See |
|---|---|
| **Attendee** | Events, agenda, people, sponsors |
| **Organizer** | Attendee management, session creation |
| **Sponsor** | Dashboard, lead forms, analytics |
| **Speaker** | Session info, Q&A, polls |
| **Reviewer** | Submission reviews |
| **Volunteer** | Assigned tasks & schedule |

## How It Works

```
App Starts
   │
   ├── Load settings & theme
   ├── Connect to API
   ├── Check internet
   └── Show login screen
         │
         └── After login → Role-based home screen
                                │
                                ├── Bottom nav (changes per role)
                                ├── Drawer menu
                                └── Real-time updates via socket
```
